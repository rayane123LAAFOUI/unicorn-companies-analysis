
 # Unicorn Companies Analysis 📊

## Project Overview
This project explores trends in high-growth companies (unicorns) between 2019 and 2021.

The objective is to identify the industries producing the highest number of unicorn companies and analyze their average valuations over time.

## Business Questions
- Which industries produced the most unicorns?
- How did the number of unicorns evolve across industries and years?
- What was the average valuation of unicorn companies in each industry?

## SQL Techniques
- Common Table Expressions (CTEs)
- INNER JOIN
- Aggregate Functions (COUNT, AVG)
- GROUP BY and ORDER BY
- Date Extraction using EXTRACT()

## Tools
- SQL
- PostgreSQL

## Dataset
The project uses a relational database containing four tables:
`companies`, `dates`, `funding`, and `industries`.

## Key Learning Outcomes
- Writing structured and efficient SQL queries.
- Combining data from multiple relational tables.
- Performing business-oriented data analysis.
- Extracting insights from company valuation data.


## Key Findings

The analysis identified the three industries with the highest number of unicorn companies between 2019 and 2021.

- **Fintech** ranked first in 2021, with 138 unicorn companies.
- **Internet Software & Services** followed with 119 companies.
- **E-commerce & Direct-to-Consumer** recorded 47 companies in 2021.
- Average valuations decreased across all three industries in 2021 compared with 2020.

These findings highlight the rapid growth in unicorn creation during 2021 and the differences in valuation trends across industries.
